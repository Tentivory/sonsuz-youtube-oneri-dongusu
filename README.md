# Sonsuz YouTube Öneri Döngüsü

## Resmi Açıklama

Bu proje, modern insanlığın en büyük krizlerinden birini bilimsel yöntemlerle simüle etmektedir: **YouTube'’un sonsuz öneri döngüsü**.

Yıllarca süren gözlemler sonucunda (ve tamamen tesadüfen) şu sonuca varılmıştır: Bir video izlemeye başladığınız anda, algoritma sizi asla bırakmaz. Bu yazılım, o döngüyü birebir (hatta daha da abartılı) şekilde yeniden üretir.

**Uyarı:** Bu kod gerçekten çalışır. Gerçekten sonsuza kadar öneri üretir. Gerçekten hiçbir işe yaramaz. Ama çok ciddidir.

## Nasıl Çalışır?

1. Python 3 yüklü olsun.
2. `python sonsuz_dongu.py` yaz.
3. Öneriler gelmeye başlasın.
4. Kaçmaya çalış. Başaramayacaksın.
5. Ctrl+C ile kurtulmaya çalış. Belki kurtulursun, belki de algoritma seni takip eder.

## Bilimsel Temeller

- Her öneri, önceki öneriden daha saçmadır.
- Bekleme süresi 5 saniyedir çünkü insan beyni daha kısasını kaldıramaz.
- Döngü sonsuzdur çünkü evren de sonsuzdur (kaynak: Kayyum Grok, 2026).
